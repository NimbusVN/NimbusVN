# 前置环境

- Emscripten SDK：先执行 `emsdk_env.bat`，确保 `EMSDK`、`emcc`、`em++` 可用。
- `VCPKG_ROOT`：依赖由 vcpkg 的 `wasm32-emscripten` triplet 构建。
- CMake + Ninja（preset 使用 `Ninja Multi-Config`）。
- Python 3；HTTPS 服务器还需要 `pip install cryptography`。

# 生成

```bat
call C:\path\to\emsdk\emsdk_env.bat
script\build-emscripten.bat
```

脚本以 `Emscripten Config` 配置并构建 Release，默认关闭 FFmpeg 和 Vulkan
（`-DUSE_FFMPEG=OFF -DUSE_RENDER_VK=OFF`），两个内核一起产出。

```text
out/emscripten/krkrsdl3/Release/
  index.html  index.js  index.wasm  index.data
out/emscripten/openartemis/Release/
  index.html  index.js  index.wasm
```

`index.data` 是 krkrsdl3 预载的 `Res/`；openartemis 没有该文件，属正常。
只构建一个内核时，在配置阶段加 `-DENGINE_KRKRSDL3=OFF` 或
`-DENGINE_OPENARTEMIS=OFF`。

# krkrsdl3（XP3/TJS）

## 准备数据

单包：把 `data.xp3` 放到 `out/emscripten/krkrsdl3/Release/`，引擎走 HTTP
Range 按需读取，不需要预载。

目录式项目：把文件放在同一目录，生成预载清单：

```bat
python platform/emscripten/genlist.py -d out/emscripten/krkrsdl3/Release
```

访问时加 `?preload=1`，文件会被预载到 MEMFS 根，用 `?args=/` 指定项目根。

## 启动服务器

```bat
python platform/emscripten/wasm_server.py 5500 out/emscripten/krkrsdl3/Release
```

首次运行会在服务目录生成自签名的 `cert.pem` / `key.pem`；浏览器提示不安全时
选择继续访问。服务器为所有响应加 COOP/COEP 头，pthreads 的
SharedArrayBuffer 才能工作。

## 打开

```text
https://localhost:5500/index.html?game=data.xp3
```

常用参数：

| 参数 | 作用 |
|---|---|
| `game=...` | 数据源，默认 `/data.xp3` |
| `args=/Res,-render=opengl` | 直接传完整 argv（逗号分隔） |
| `render=opengl` | 渲染后端（WASM 只编 GL / 软件） |
| `debug=1` / `window=...` / `scale=...` / `fullscreen=1` | 调试与窗口参数 |
| `preload=1` | 预载同目录 `filelist.json` 中的文件 |

示例：

```text
https://localhost:5500/index.html?game=data.xp3&render=opengl
https://localhost:5500/index.html?preload=1&args=/
```

必须通过 HTTP(S) 打开，不能直接用 `file://`。

# openartemis（PFS/Artemis）

## 准备数据

- 单包：把 `root.pfs` 放到 `out/emscripten/openartemis/Release/`。
- 解包目录：把包含 `system.ini` 的那一层文件放到服务目录，生成预载清单：

```bat
python platform/emscripten/genlist.py -d out/emscripten/openartemis/Release ^
    -e pfs ini psb ogg opus wav png jpg webp mp4 dat tjs csv
```

`-e` 按项目实际资源类型补全。

## 启动服务器

```bat
python platform/emscripten/serve.py out/emscripten/openartemis/Release 8080
```

`serve.py` 是纯标准库 HTTP 服务器，同样返回 COOP/COEP 头。它只适合本机
`localhost`（属于安全上下文）；从手机或局域网访问请改用 `wasm_server.py`
（HTTPS，自签证书）：

```bat
python platform/emscripten/wasm_server.py 5500 out/emscripten/openartemis/Release
```

## 打开

```text
http://localhost:8080/index.html?pfs=root.pfs
```

参数：

| 参数 | 作用 |
|---|---|
| `pfs=root.pfs` | 服务器同目录的单包 |
| `args=/data/root.pfs` | 直接传引擎 argv |
| `preload=1` | 预载同目录 `filelist.json`，文件放到 `/data`，项目根为 `/data` |
| `dir=PATH` | 直接把已写入 MEMFS 的路径传给引擎 |

不传参数时，用页面上的“选择 .pfs 文件 / 选择游戏目录”交互启动。存档在
IndexedDB（IDBFS），与服务器目录无关，换浏览器配置会清空。

# 备注

- 页面自带日志、进度和错误面板；打不开时先看浏览器控制台和服务器输出。
- `wasm_server.py` 生成的 `cert.pem` / `key.pem` 在服务目录里，不要提交。
- Emscripten 构建默认关闭 FFmpeg 与 Vulkan，视频/渲染走各自的回退路径。
